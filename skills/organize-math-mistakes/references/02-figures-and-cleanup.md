# 题图保真、裁剪与去作答痕迹

## 1. 先判断图的作用

数学题图承载的不仅是外观。处理前列出它给出的事实：对象数量、行列、分组、连接、相邻边、箭头起止、刻度、标签、遮挡和选项之间的区别。

例如10朵花分成两组5朵，与左5右4的9朵花，对应的算式可能分别为乘法和加法。不能把两幅图都整齐化成相同阵列。

## 2. 决策表

| 情况 | 推荐处理 | 必查内容 |
|---|---|---|
| 复杂插图清楚且未被作答覆盖 | 保留准确局部原图 | 所有必需部分和标签都在裁剪内 |
| 规则点阵、网格、数轴，事实完全清楚 | 可程序重绘 | 数量、分组、刻度、箭头、原题留白一致 |
| 原图上只有外围教师标记 | 调整局部裁剪或重排题干 | 不裁掉边缘对象和说明 |
| 手写覆盖文字但印刷内容可明确恢复 | 转写印刷内容，恢复空白 | 不能按手写答案反推题干 |
| 手写与复杂题图混在一起 | 优先寻找可读局部或清晰来源；确实能分离才清理 | 对象和结构没有误删、补造 |
| 原设计遮挡块、缺口或问号 | 原样保留其解题作用 | 不把它当污点去掉 |
| 关键图形无法辨认 | 标记具体待核对位置 | 不绘制猜测结构作为原图替代 |

如果当前环境对图像编辑工具有明确要求，遵循该环境要求。无论使用何种工具，数学对象数量和关系都要逐项核对。生成式修图的结果不能仅凭视觉整洁验收。

## 3. 裁剪的可靠步骤

1. 查看完整原图和实际尺寸，确定当前使用的图片已经处于正确方向。
2. 针对这张图测量目标区域。像素坐标通常以左上为原点，向右为x、向下为y。
3. 保存`left, top, right, bottom`及对应来源文件，确认`0 <= left < right <= width`、`0 <= top < bottom <= height`。
4. 如果进行了旋转、透视校正或缩放，先保存处理后的来源，再在该图上重新测量坐标。
5. 裁剪出独立图片并打开查看，确认没有切掉边缘对象、括号、图例、计数笔画、最后一列或箭头端点。
6. 放进PDF后检查实际打印大小，判断数字和对象能否辨认。

通常在图外保留少量边缘。紧贴对象的裁剪更容易漏掉笔画；包含大段手写和其他题的裁剪也不适合干净题目版。

### 实际裁剪与显示裁切

PDF画布的clip操作只限制显示区域，有些做法仍将完整照片嵌入文件。最终使用独立裁出的局部图，可以避免把整页作答照片夹带进成品。

已有流程采用过“局部PDF再渲染为PNG”的方式，普通图片也可以用确定性的像素裁剪工具。二者都要打开裁出结果检查，不能只看生成成功。

如果使用缓存，缓存键包含源图片内容标识、裁剪区域和旋转/缩放信息。仅凭“第7页＋坐标”命名会在换一张原图后错误复用旧图。小批次直接使用每次独立的工作目录也能避免混淆。

## 4. 重绘各类图时检查什么

### 点阵与分组图

- 记录总数量、几行几列、间距、外围分组线。
- 一个3行6列阵列可表示按行或按列分组；三个单独圈住的“两件一组”图不一定具有相同分组含义。
- 保留剩余零散点，不能为了乘法整齐而补齐。
- 原题要求学生圈分组时，题目版不预画答案圈。

### 数轴

- 确认起点、终点、每格表示多少、哪些刻度带数字。
- 一次跳跃的格数、跳跃次数和终点分别记录。
- 区分原题印刷跳跃与学生应补画的跳跃。前者保留，后者留白。
- 向左和向右的箭头不可互换；回跳与前进不是同一运算。
- 附带工具的`arcs`使用刻度数组下标。若`values=[0,6,12,18,24]`，从0跳到18写`[0,3]`，不是`[0,18]`。
- 等距离标签必须对应等数值间隔；非均匀轴使用独立核对过的图，不强行用等距模板。

### 立体积木

- 按层或列分析，注意一个正方体可能显露多个面，不把面数当块数。
- 可由明确可见的支撑关系确定的隐藏块可以计入，并写出依据。
- 后侧模糊或结构有多种可能时，不能仅因为常见答案而补出隐藏块。
- 复杂立体图优先保留原图，避免简单重绘改变遮挡关系。

### 正字计数与表格

- 表头、行标签、列标签和图中被遮挡部分一并保留。
- 数完整的“正”字，再逐笔数未完成部分。未写完的正字不能直接用一个相似汉字替代，字体笔画不等于原图计数笔画。
- 题目问“可能”时，可见笔画可能只用于建立下界，不一定要得出唯一实际次数。
- 裁剪边界要保留最右侧残余笔画。例如最后的一竖也可能是题目证据。

### 拼桌、小棒和相邻图形

- 明确共享的边是否需要重复计数。
- 拼桌的接触边是否仍可坐人，看原图布置，不固定套公式。
- 并排方形与十字形排列即使正方形数量相同，也分别核算外边与共享边。
- 连线连接哪两个点、图案轮次和增长规律都属于原题信息。

## 5. 图片尺寸与清晰度

保留纵横比。将图宽设为`w`、原图像素为`iw × ih`时，展示高为`w × ih / iw`。

放大能方便查看现有像素，不能恢复本来没有记录的细节。小图大幅放大仍模糊时，优先寻找清晰来源、确定性重绘可确认的简单图，或标记待核对。

用150–200 DPI的PDF页面渲染检查普通排版；检查细小笔画可提高到300 DPI。提升渲染DPI不会增加原图本身的细节。

## 6. 题图验收表

每幅参与解题的图至少回答：

- 它对应哪个来源、页码、题号？
- 选的是原图局部还是重绘？
- 其中有几个对象、怎样分组、有哪些方向或共享关系？
- 哪些是题目给定，哪些应由学生完成？
- 标记/清理之后，以上事实是否保持？
- 在最终PDF上是否能清楚数出、看懂？

如任一关键问题没有依据，不把该题标为已核对完成。
