# 输入、选题与逐题转写

## 1. 建立本批工作目录

建议将本次任务放在单独目录中：

```text
本次任务/
  sources/             原始材料的稳定副本
  figures/             裁出的干净题图、已核对的重绘图
  selection.md         全部候选题及收录/排除依据
  questions.json       本次收录题的结构化数据
  review.md            疑点、答案验证、渲染检查记录
  output/pdf/          最终题目和答案
  tmp/pdfs/            本次渲染和观察用的中间文件
```

目录是建议，用户已有结构时沿用即可。关键是来源稳定、图与数据能找到、输出不误覆盖其他批次。

用户附件如果位于剪贴板或系统临时目录，先复制需要的原图到 `sources/`。不要把临时附件的绝对路径写进可复用技能或依赖它长期存在。不要覆盖原图。PDF按本次选题需要渲染原页面；来源页与输出页分别记录。

## 2. 清点全部输入

对每个输入记录：

| 字段 | 填写方式 |
|---|---|
| 来源 ID | 自己分配唯一的 `bookA`、`bookB` 等 |
| 来源名称 | 用户给出的教材名；没有时用“材料A”等明确代号 |
| 文件 | 当前可访问的稳定路径 |
| 文件内页序 | PDF第几页、图片列表第几张；从1开始给人阅读 |
| 印刷页码 | 以纸面印刷为准，不能用输出PDF页码冒充 |
| 图片尺寸 | 实际宽、高；用于确定裁剪坐标 |
| 可读性 | 清楚、局部需要放大、关键位置缺失 |

两份教材都出现“第7页第6题”是正常的，以来源区分。连续拍摄的同一页有重叠时比较内容和位置，避免重复录入同一题；不同来源的相似题默认分别保留，除非用户要求去重。

## 3. 选题判断步骤

1. 先读本次用户要求，记录是否指定页码、题号、标记颜色、整题/小题、是否全部整理。
2. 实际看每一页，找圈选、叉号、批注等标记的位置。
3. 把标记对应到题号，不能仅按附近最近的一段文字推定。
4. 有小题时，判断标记只落在小题上还是明确指向整题。
5. 判断选中小题是否依赖公共题干、公共图、其他必要条件；一并保留所需条件。
6. 回看全页，从上到下、从左到右扫一遍，检查有没有漏掉边缘或页底标记。

题号出现在材料描述中，不等于用户已明确指定收录它。若用户要求“只整理有标记的题”，而某题的标记状态未提供，把它列为候选待核对，不自行写成“红圈”。若用户明确说“以下这几题都要整理”，则依据记为“用户指定”，无需另找圈选。选题依据只写实际观察或用户明确指令。

### 范围决策表

| 观察 | 处理 |
|---|---|
| 用户明确指定第5题 | 收录第5题，不因未圈出而遗漏 |
| 用户明确指定第5题（2） | 收录（2）和解答它必需的公共信息 |
| 圈号明确包围（2） | 按小题收录，不自动增加（1）（3） |
| 勾/叉标在某个作答空处 | 按本次“整理错题”的语境判断其对应小题 |
| 红线横跨两题、指向不明 | 记录两个候选位置，放大确认，仍不明再问 |
| 整页无标记、用户仅说“整理错题” | 先看是否有明确题号说明；没有则需确认范围，不自动收录整页 |
| 用户明确要求全部题目 | 收录全部，手写批改不作为排除依据 |

清单可以用一张表：

```text
ID | 来源 | 原页码 | 原题号 | 收录? | 依据 | 所需公共信息 | 疑点
bookA-p007-q006-s04 | 材料A | 7 | 6（4） | 是 | 小题旁红圈 | 第6题公共说明 | 无
bookA-p007-q006-s01 | 材料A | 7 | 6（1） | 否 | 不在本次指定范围 | - | 无
```

`questions.json`只放本次收录题；排除记录保留在选题清单中。题目可将同一大题的选中小题分条保存，但输出时编号须能看出原有关系。

区分“明确不在范围内”和“标记信息尚未提供”：后者记录为候选待核对，不把缺少证据写成已经确认没有标记，也不进入正式答案清单。

## 4. 转写的四遍核对

### 第一遍：看整题

读完整题干、全部必要图、选项和单位。先理解要求是填空、圈选、画图、连线、比较还是列式。

### 第二遍：录入印刷信息

逐字转写，尤其检查：

若输入只是对原题的摘要或人工观察，保留已提供的原文与事实，把缺少的公共题干标记出来。需要整理语言时，仅做不改变条件的连接；不要把选项移写成图中的数据，也不要声称摘要就是逐字识别的完整原题。

- `+`、`-`、`×`、`÷`、`=` 与 `>`、`<`。
- `□`、`○`是否表示待填写数字/运算符，还是代表一个未知数的图形。
- “相加”与“相乘”，“个”与“和”，“多”与“少”，“至少”与“可能”。
- 题目要求的算式数量、所选数字数量、是否同一组数字。
- “一共”“还差”“每次”“每个”“3天”等限制条件。
- 括号外单位是“个”“根”“米”“分钟”，不要顺手替换。
- 多个小题的序号和顺序。

### 第三遍：区分作答与题干

印刷字体、对齐方式、颜色、笔迹只作判断线索，要结合内容和上下文。

- 学生填入的数字从题目版移除，恢复原有空白。
- 学生画的圈、连线、箭头、涂色如果属于作答，题目版移除。
- 教师的勾、叉、分数和批注不进入干净练习题，选题记录可以保留其作用。
- 原印刷的数轴跳跃、计数笔画、遮挡块、示例步骤属于原题，保留。
- 若无法判断一条线是印刷还是学生作答，回看同页同类图或原题说明，不凭美观处理。

### 第四遍：反向对照

从转写内容回到原图，每个数字、符号、条件和选项逐一指认。确认不是从以前相似题中记忆补全。

建议一批约3–5题，完成本批四遍核对再继续。遇到较难题图可单独处理一题。

## 5. 不确定性怎样记录

把“已看到的事实”和“推断”分开，例如：

```text
事实：题干写要搭5个图形，已有8块；图中能辨认4块。
缺失：后侧结构严重模糊，无法判断是否另有隐藏块。
状态：needs_review。
待确认：每个完整图形究竟有几块，或提供这一局部的清晰图。
```

不要把“常见这种题一般有5块”写成事实。不要使用一个自信百分比替代证据。

对于题目本来设计的遮挡，先检查是否仍可由可见信息和选项解答。能解答时不必要求用户提供无遮挡原图；见数学核验参考的“可能值”案例。

范围/原题识别出现实质歧义时，提出一个具体问题；已清楚的题继续整理。若要先交部分结果，说明哪些题待核对，不能静默漏掉它们。

## 6. 进入排版前的记录

每个收录题应有以下信息，即使其中一部分保存在旁边的核对文件：

- 唯一 ID、来源、原页码或图片序号、原题号和选取依据。
- 完整题干、作答动作、选项、必要公共信息。
- 图来源、图处理方式、需要保留的结构。
- 答案和验证（若本次要求答案）。
- `ready`或`needs_review`状态及具体疑点。

只有已经实际核对过的题才标为`ready`。这不是脚本自动判断的置信度，而是本次执行者的核对状态。
