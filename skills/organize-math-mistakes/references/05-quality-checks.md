# 最终检查与交付

## 1. 检查记录

在本次工作目录的`review.md`记录以下结果。只勾选实际执行并通过的项目，不照抄一份全勾清单。

```text
本批标题：
原始材料数：
选中题组数：
选中小题数（如与题组数不同）：
题目PDF页数：
答案PDF页数：
已查看的最新渲染页：
仍需核对的题ID和问题：
```

题组数与小题数分别计算：第7题包含3个小题，可是一组3小题；不能把“12个题组”误报成“12个小题”。用户未要求数量统计时，交付说明可以不报数，但内部仍做对应检查。

## 2. 选题与来源核对

- [ ] 每个用户明确指定的题/小题都在收录清单中。
- [ ] 每个按标记选中的题都能对应到实际原图位置。
- [ ] 未选小题没有因为复制整题而误收录。
- [ ] 解答所需的公共题干、公共图和单位已经保留。
- [ ] 不同教材/来源的同页同题号没有合并覆盖。
- [ ] 印刷页码、输入页面序号和输出页码没有混淆。
- [ ] 重叠拍摄的同一题没有重复收录，或按用户要求保留。
- [ ] 有歧义或无法恢复的题被记录，未静默删去。

## 3. 题目内容核对

- [ ] 对照原图核对全部数字、运算符、图形符号、题号。
- [ ] “相加/相乘、和/个、可能/至少、还差/一共”等关键用词一致。
- [ ] 选项内容、顺序、单位和作答动作一致。
- [ ] 学生手写答案、教师勾叉不出现在干净练习题中。
- [ ] 原题印刷提示、表头、例子和必要遮挡保留。
- [ ] 题目中应空着的数字、运算符、圈选和画图部分保持可作答。
- [ ] 没有将以前相似题的内容填进本批原题。

## 4. 图形核对

逐幅参与解题的图完成检查：

- [ ] 裁剪区域完整，无缺失最后一笔、边缘对象、表头或图例。
- [ ] 点阵的总数、行列、分组和剩余项与原图一致。
- [ ] 数轴的刻度、方向、起止、跳跃次数与给定/待画部分一致。
- [ ] 积木按块计数，有隐藏块时依据明确。
- [ ] 拼图或拼桌的相邻关系、共享边和座位位置一致。
- [ ] 正字图的完整字与残余笔画均保留，没有替换成计数不同的符号。
- [ ] 题目设计的遮挡块未被误删。
- [ ] 未因去手写、修图或重绘增加/减少数学对象。
- [ ] 成品中使用实际局部图，不夹带完整作答照片。

## 5. 答案核对

- [ ] 每一题从原题独立求解，未照抄学生答案。
- [ ] 每一个结果都已代回条件或通过独立计数/计算验证。
- [ ] 不仅算术成立，也满足题目对数字组数、算式数量、范围的全部限制。
- [ ] “可能值”按可见条件排除选项，没有声称知道隐藏的精确内容。
- [ ] 多解题给出完整可行的一组，并说明可接受的等价答案。
- [ ] 取值范围有上下文依据；真正的歧义明确记录。
- [ ] 单位、数量对象、往返次数、连接次数和已给的时间范围正确。
- [ ] 画图题的答案足以表达应画内容，必要时有答案图。
- [ ] 答案按与题目相同的来源和顺序对应，没有串题。

若只交题目，本节无需假装执行；记录“本次未要求答案”。

## 6. 页面检查

先渲染最新PDF，再实际查看每页：

- [ ] 字体清楚，无缺字、乱码、黑方块或不可辨认符号。
- [ ] 方框、圆圈、括号空白足够书写，与正文不重叠。
- [ ] 长句换行没有把关键符号或空白拆到难以理解的位置。
- [ ] 标题、来源标签、正文、题图、答案、页脚之间没有碰撞。
- [ ] 题图清晰，保持纵横比，标签可读。
- [ ] 题号不会孤立在页尾，所需题干/图/作答位置关系清楚。
- [ ] 跨页题目有清楚的来源或续题说明；下页图不脱离上下文。
- [ ] 文本与图不超出纸张和可打印区域，页底不被截断。
- [ ] 作答留白适合该题；没有靠过小字号把内容强塞一页。
- [ ] 题目版不出现参考答案内容，答案版不混入未核实猜测。
- [ ] 页码连续，文件名与本批标题一致，未误链接旧版文件。

## 7. 返工规则

看到问题后定位它属于：选题、转写、题图、答案还是排版。修正源数据或相应工具后重新生成，避免直接改PDF却让源数据保持错误。

如果修改会改变分页，检查之后受影响的全部页面。若只替换同尺寸的局部图且分页未变，重点复核受影响图、对应答案和所在页。

同一处在重新放大、对照上下文后仍无可靠证据，记录待核对并提出具体缺失信息；继续推进其他清楚部分。不要无限重复同一种无效识别，也不要为了结束任务掩盖不确定性。

## 8. 交付状态怎样表述

### 已完整核对

给出题目版和答案版的实际文件链接，简短说明已按原页码题号对应并检查。用户没有要求时，不展开排版代码和中间文件。

### 有待核对项

使用清楚标记的草稿或说明已完成部分，列出待核对的来源/题号和缺失信息。例如“材料A第7页第7题（2）的后侧积木数无法辨认，待确认；其余已整理”。不要说“全部正确”。

### 未完成视觉查看

如实说明PDF已生成但哪些页面还未完成视觉检查。不能仅因程序运行成功而声称排版无误。

本技能提高流程可重复性，但不会使看不清的图片变清晰，也不保证任意模型不会犯错。完成标准由本批真实证据和实际检查决定。
