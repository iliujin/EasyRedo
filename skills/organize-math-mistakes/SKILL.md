# 小学数学错题整理

## 目标与适用范围

把用户提供并指定的数学题整理成便于重新练习的题目 PDF，并在需要时生成对应的参考答案 PDF。以原题信息准确、题图语义不变、答案有验证、纸面可写为完成标准。

本技能面向能够看图、读写文件、执行脚本的 agent。使用较低能力模型时，也要实际打开原图并执行检查。文字模型仅接到图片路径时并不能识别图片；应使用当前环境提供的视觉/OCR工具，或请求可读材料，不推测图片内容。技能本身不提供模型、OCR服务或额外文件权限。

本技能来自已被用户认可的中文小学数学错题整理流程。保留成功流程，具体数字、答案、照片坐标和文件路径每批重新确认。用户本次明确要求优先于默认设置。

## 启动时按这个顺序阅读

1. 阅读本文件，确定本次输出与选题范围。
2. 开始识别前，读 [01-intake-and-transcription.md](references/01-intake-and-transcription.md)。
3. 有图形、表格、数轴、手写覆盖时，读 [02-figures-and-cleanup.md](references/02-figures-and-cleanup.md)。
4. 需要答案时，读 [03-math-verification.md](references/03-math-verification.md)。
5. 开始生成 PDF 前，读 [04-pdf-production.md](references/04-pdf-production.md)，按其中的数据格式调用附带工具。
6. 交付前，逐项执行 [05-quality-checks.md](references/05-quality-checks.md)。

不要只读目录标题就执行。每完成一个阶段，把该阶段的结果保存到本次工作目录；下一阶段从已核对记录继续，不依靠对话记忆重新猜测。

## 默认设置与可变要求

| 项目 | 未另行指定时的做法 | 何时改变 |
|---|---|---|
| 输出 | 分开的题目 PDF 和参考答案 PDF | 用户只要题目、只要答案或要求其他格式时按其要求 |
| 选题 | 按明确指定的题号或圈选/批改标记 | 用户说“全部整理”时收录全部；标记不清时先核对 |
| 编号 | 来源名称＋原页码＋原题号，保留小题号 | 无印刷页码时用图片序号，明确标作图片序号 |
| 正文 | 重排印刷题干，学生答案留空 | 用户要求原样存档时保留原样，不套用去手写流程 |
| 题图 | 保留与题意有关的结构、数量、顺序、方向和遮挡 | 仅在不改变题意且信息已确认时重绘 |
| 纸张 | A4 纵向，边距约 15–16 mm | 用户指定纸张、方向或模板时改变 |
| 风格 | 白底、深色正文、少量墨绿色标题 | 用户要求黑白或既有其他模板时改变 |
| 作答空间 | 根据题型留空，优先保证可写 | 用户明确要求紧凑版、放大版时调整 |
| 数学表达 | 保留原题表达与所学范围 | 不用解题方便替换原题条件 |

选题依据按“本次明确题号/范围 → 本次说明的标记 → 原图清晰标记”判断。不要把整页所有题自动视为错题，也不要把某一次的范围固化成永久默认。

## 核心工作顺序

### 阶段 1：建立来源与选题清单

- 实际打开每张原图或 PDF 页面，记录教材/来源、印刷页码、图片序号、分辨率。
- 将本次需要的临时附件复制到本次工作目录的 `sources/`，保留原文件。
- 逐题记录：唯一 ID、来源、页码、题号/小题号、是否选取、选取依据、是否有图、疑点。
- 推荐 ID：`bookA-p007-q006-s04`。来源不同，即使页码题号相同，也分别保留。
- 圈中一个小题只整理该小题，并带上解答它所需的公共题干或公共图。
- 选题依据只记实际观察或明确指令；材料描述没提到圈选时，不替它编一个圈选标记。

**本阶段结束条件：**每个用户指定或明确标记的题都能在清单中找到；排除的题有范围依据；不清楚的范围单独标记。

### 阶段 2：逐题恢复干净题目

- 每批处理约 3–5 题：看原图、放大关键区域、转写、回看核对，然后处理下一批。
- 区分印刷题干、学生作答、教师标记与题目原有图形。按原印刷内容制作可重新作答的空白题。
- 保留小题顺序、选项、单位、括号、表头、提示、作答动作。例如“圈出来”和“列式计算”不是同一种输出。
- 对需要画一画或补充数轴跳跃的题，保留原题给定部分，学生应完成的部分留空。
- 对看不清的数字、运算符、方块或条件先放大复核。仍无证据则记录具体疑点，不写一个看起来合理的数字补全。

**本阶段结束条件：**题干与原图逐项对应，作答痕迹已与印刷内容分离，题图处理方式已确定。

### 阶段 3：恢复题图

- 先判定图是否承载解题信息。点阵数量、分组、数轴箭头、相邻关系、遮挡图块、统计笔画都属于信息。
- 复杂原图优先保留准确的局部图；简单且信息完全清楚的点阵、规则网格、数轴可以重绘。
- 每幅图采用当前原图的坐标，不套用以前文件的坐标。最终 PDF 嵌入实际裁出的局部图，避免只做显示裁切却夹带整页照片。
- 清理手写不得改变原印刷内容；题目设计的遮挡块应保留。具体决策见图形处理参考文件。
- 无法准确恢复时，在内部记录 `needs_review`，继续处理其他清楚的题。

**本阶段结束条件：**图的数量、位置关系、标签、方向与原题一致，原题要求学生填写/补画的部分没有被代做。

### 阶段 4：独立解题并核验

- 从清理后的原题重新求解。手写答案和教师批改用于判断选题，不当作标准答案。
- 每题至少保存“答案＋简短验证”。验证应代回原式、按不同方法重数，或检查全部题目条件。
- 最终答案、对应算式和核验结果的数值必须一致；多因数连乘先展开全部因数再实际复算，不保留被否定的猜测答案。
- 先查含义，再算数值。例如“2个5相乘”是 `5 × 5`；“2和5相乘”是 `2 × 5`。
- 有多个正确答案时给出符合题目要求的一组，并说明是示例答案。无需把全部可行答案都塞进题目版。
- 根据实际年级/章节说明必要的取值范围。已有“二年级乘法”上下文时可以按非负整数给出答案，备注范围，不为常规教学假设反复打断用户。
- 仍有实质性缺失条件时，保留“待核对”状态，不为了生成完整 PDF 填入猜测答案。

**本阶段结束条件：**每个答案都满足整道题的条件，并且能用保存的验证解释其正确性。

### 阶段 5：生成 PDF

- 阅读排版参考，填写 `questions.json`。已有脚本可作为工具参考，题目数据不混入通用排版代码。
- 优先调用 [build_workbook.py](scripts/build_workbook.py)，它支持正文、留空算式、局部图片、规则点阵和等距数轴。
- 模板能力不足时，为本批增加局部绘图工具或定制排版；保持相同的来源记录和检查标准。不要把复杂图改成模板支持的另一幅图。
- 题目版保留练习空白，答案版带来源标签、答案和简短核验。题目与答案从同一份清单按同样顺序生成。
- 遇到题目过长，按小题或段落合理分页并复查；不用无限缩小字号挤进一页。
- 默认工具拒绝把 `needs_review` 题当作最终版本输出。确需先提供可核对版本时使用 `--draft`，文件名和页面会显示“待核对”。

**本阶段结束条件：**目标文件已经生成且可以打开，清单中的题均有对应位置。

### 阶段 6：逐页检查与交付

- 用 PDF 渲染工具生成每页图片并实际查看。文字提取和脚本成功仅能辅助检查，不能代替看页面。
- 比对选题清单，核对题目数、原页码、小题号、题目版与答案版对应关系。
- 重新检查包含数轴、计数表、立体图和新绘图的题，确认没有改变题意。
- 检查缺字、黑方块、空白占位框、运算符、断行、重叠、截断、页脚和作答空间。
- 修改后重生成并检查受影响的页面；会改变分页时检查之后所有受影响页。
- 交付可点击的最终文件链接。简短说明是否有待核对项，不声称完成未执行的检查。

**完成条件：**内容、答案、图形、排版四项检查均有实际记录；仍存在的疑点明确披露，不隐藏在成品中。

## 遇到问题时采取什么动作

| 当前情况 | 下一步 |
|---|---|
| 原图清晰、范围明确 | 直接按流程处理，无需逐步请求确认 |
| 用户说“和之前一样”，已有可查看成品 | 参考其输出样式，不复用其题号、答案或图坐标 |
| 暂时看不清一个位置 | 定位并放大该区域，再与完整题干交叉核对 |
| 放大和重读后仍无法判断 | 记录具体缺失信息，只针对该处提问；其他题继续 |
| 题中有原设计遮挡、问“可能” | 保留遮挡，利用可见信息和选项判断可能性，不要求还原所有隐藏信息 |
| 缺少必需文件或视觉工具 | 如实说明缺少什么，处理已有可读部分，不伪造识别结果 |
| 运行依赖/字体不可用 | 按排版参考定位当前环境依赖；不要硬套旧电脑绝对路径 |
| 生成成功但有排版缺陷 | 修正并重新渲染，不以退出码替代视觉检查 |

## 本技能包含的可复用材料

- `references/`：按阶段拆开的详细步骤、易错情形、判断示例、数据格式和验收清单。
- `scripts/build_workbook.py`：从已核对 JSON 生成题目、答案及生成记录；不负责识图与解题。
- `scripts/test_build_workbook.py`：真实生成测试，验证分页、编号、草稿标记和输入拒绝行为。
- `assets/example-questions.json`：可直接运行的排版示例，演示数据格式。示例题不是新任务的默认选题。
- `assets/example-flower-left.png`：示例所需的已裁出题图。复制示例时连同此图一起复制。

## 成功经验应如何迁移

迁移“来源可追溯、按标记选小题、印刷与手写分离、题图保真、独立解题、逐页查看”的做法。

对每一批材料重新确认原题事实。较低能力模型尤其要完成每阶段的结束条件；详细说明不能替代看图证据、数学计算或执行结果。
